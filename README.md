# 🛒 Lista de Compras

Aplicação web responsiva para gerenciamento de listas de compras, desenvolvida com HTML, CSS e JavaScript.

O projeto foi criado como um projeto prático de estudo e evolução em desenvolvimento web front-end.

## 📋 Sobre o projeto

A aplicação permite criar e gerenciar uma lista de compras de forma simples e visual.

O objetivo é desenvolver o projeto gradualmente, utilizando JavaScript para manipulação do DOM, eventos, arrays, funções e armazenamento de dados no navegador.

## ✨ Funcionalidades

- [x] Adicionar itens à lista
- [x] Adicionar itens pressionando `Enter`
- [x] Marcar itens como comprados
- [x] Riscar itens comprados
- [x] Editar itens
- [x] Excluir itens
- [x] Barra de progresso das compras
- [x] Animação ao completar a lista
- [ ] Salvar lista utilizando Local Storage
- [ ] Reorganizar itens comprados para o final da lista
- [ ] Criar uma nova lista após concluir as compras

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript
- Local Storage *(em desenvolvimento)*

## 📱 Responsividade

A aplicação foi desenvolvida para funcionar em diferentes tamanhos de tela, incluindo computadores, tablets e celulares.
